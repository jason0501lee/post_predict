# 社群媒體貼文分析預測工具

這是一個使用 Python 和 Streamlit 開發的社群媒體貼文分析預測工具。此工具可以幫助用戶分析貼文內容，並提供各種預測指標和優化建議。

## 功能特點

- 貼文互動率預測
- 未來7天走勢預測
- 觀眾群體分析
- 最佳發文時間建議
- 內容優化建議
- 視覺化數據展示

## 安裝說明

1. 確保您已安裝 Python 3.8 或更新版本
2. 克隆此專案到本地
3. 安裝所需套件：
   ```bash
   pip install -r requirements.txt
   ```

## 使用方法

1. 在終端機中進入專案目錄
2. 執行以下命令啟動應用程式：
   ```bash
   streamlit run app.py
   ```
3. 在瀏覽器中開啟顯示的網址
4. 在文字框中輸入要分析的貼文內容
5. 點擊「開始分析」按鈕查看結果

## 系統需求

- Python 3.8+
- 網路連接
- 現代網頁瀏覽器
